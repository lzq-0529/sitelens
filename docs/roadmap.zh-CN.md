# 和同类项目比，SiteLens 还缺什么

SiteLens 不想同时做成 GA4、Matomo、PostHog 和 Uptime Kuma。
这一页老实写：邻居们今天哪里做得比我们好、我们接下来补什么、什么故意不做。
更新于 2026-11-04。

## 我们已经不一样的地方

| | Umami / Plausible | Matomo | PostHog | Uptime Kuma | **SiteLens** |
| --- | --- | --- | --- | --- | --- |
| 最擅长 | 访问量、来源、简单目标 | GA 式深度、细分、电商 | 产品事件、回放、实验 | 网站活没活、证书、状态页 | **国内站 + 海外站的店铺运营** |
| 下单漏斗到已支付 | 目标级 | 有，但重 | 自己拼事件 | 无 | **浏览→商品→加购→结账→支付，内置** |
| 知乎/小红书/百度来源 | 通用来源 | 通用来源 | 自己拼 | 无 | **开箱命名** |
| 搜索引擎 + AI 爬虫 | 当机器人过滤掉 | 部分 | 无 | 无 | **SEO 标签页 + 爬虫日志** |
| AI 问答引用（GEO） | 无 | 无 | 无 | 无 | **15 家，含 DeepSeek/豆包/Kimi** |
| 国内外域名拆分 | 多站点，无区域语义 | 靠细分 | 自己拼 | 无 | **`cn_hosts` / `intl_hosts`** |
| 部署 | Node+Postgres / ClickHouse | PHP+MySQL | 一堆服务 | Node+SQLite | **FastAPI + 一个 SQLite 文件** |

一句话定位：*Umami 告诉你「来了流量」，SiteLens 告诉店主「流量是不是搜索引擎/AI 带来的，最后付没付款」。*

## P0：先补这些，不然陌生人用不下去

大致按这个顺序：

1. **英文界面（中英切换）。** README 已经双语，后台今天只有中文。这是海外店主和大多数合集审核者眼里最大的门槛。
2. **实时访客。** 「现在谁在店里」（近 5/30 分钟、正在看哪页、什么来源）。Umami/Plausible 用户默认期待这个，我们只有 7/28/90 天。
3. **多店铺。** 一个后台管多个店/品牌，可切换。今天一个 SiteLens 只能管一对国内+海外站，代运营和双品牌直接卡住。
4. **投放归因。** 拆 `utm_medium` / `utm_campaign` / `utm_term`（今天只认到来源），并能看每个活动、每个 SKU 的落地→加购→付款。
5. **导出、保留、备份。** 访客/订单/爬虫的 CSV/API 导出、可配的数据保留与自动清理、写清楚 SQLite 怎么备份恢复。自托管用户不会把唯一一份数据放黑盒里。
6. **告警通道 + 异常。** 日告警 webhook 已有。补 Slack / Telegram / 飞书 / 企业微信 / 邮件，再加「流量骤降 / N 小时没订单 / 爬虫不来了」，而不是只在固定时间推一次。
7. **可用性 + 证书小监控。** 不做 Uptime Kuma 克隆：每个已配域名一个 HTTP 检查、证书剩余天数、挂了/恢复走同一个 webhook。搜「网站监控」的人会找这个词，我们今天完全没有。

## P1：店主第二批会问的

- **路径与留存：** 访客路径（落地→商品→加购）、新客/回访、跳出与停留。设备/浏览器数据已经存了，要完整露出来；国家/城市只用离线 GeoIP 文件，不调云接口。
- **电商深度：** 客单价、复购、单品转化率（看了→买了）、弃购名单（开始结账没下单）、按渠道/优惠码看收入。
- **SEO 深度：** Google Search Console + 百度站长数据导入并排爬虫日志、按爬虫状态出 404/坏路径报告、sitemap/robots 健康检查、可选关键词排名快照；tracker 顺手采 Core Web Vitals（LCP/CLS/INP）。
- **GEO 深度：** 竞品声量占比随时间趋势、单个提问词的历史曲线、情感倾向、更多一键 Agent。今天 GEO 是张表，还不是趋势。
- **一键接入：** Shopify 应用/主题片段、WooCommerce 插件，而不是「自己贴脚本 + 手配 webhook」。
- **分享：** 只读分享链接、每周自动报表（邮件/webhook 发 PDF 或图片）给合伙人/老板看。

## P2：故意不做

- 热力图 / 会话回放——重、且和隐私定位冲突，那是 PostHog/Matomo 的活。
- 功能开关 / A-B 测试——产品分析的活，不是店铺运营。
- 广告花费同步（Google/Meta Ads 成本导入）——P0 的活动归因没做完之前不碰。
- 多租户 SaaS 计费 / 官方云托管——SiteLens 就是让你自己跑的东西。
- 全量日志分析 / APM / 服务器指标——和 Uptime Kuma、Netdata、GoAccess 搭配用，不要重造。

## 怎么影响这个清单

提 Issue 时写清你的店长什么样（Shopify/Woo/自建、国内/海外、月订单量）。
最有用的 一句话是：「我没法从 Umami 换过来，因为缺 ___。」
